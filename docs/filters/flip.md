# `flip`

> fg:flip=horizontal|Mirror subject horizontally or vertically.

| Field | Value |
|---|---|
| **Category** | geometric |
| **Valid layers** | fg only |
| **Signature** | `flip=horizontal\` |
| **Backed by** | vertical |
