# `flip`

> Mirror subject horizontally or vertically.

| Field | Value |
|---|---|
| **Category** | geometric |
| **Valid layers** | fg only |
| **Signature** | `flip=horizontal\|vertical` |
| **Backed by** | `CIAffineTransform` mirror |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "fg:flip=horizontal"
```
