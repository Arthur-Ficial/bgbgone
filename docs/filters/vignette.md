# `vignette`

> Darken the edges. Composite-only.

| Field | Value |
|---|---|
| **Category** | composite |
| **Valid layers** | all only (composite) |
| **Signature** | `vignette=intensity:radius` |
| **Backed by** | CIVignette |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "all:vignette=2:1"
```
