# `pointillize`

> Seurat-style dot pattern.

| Field | Value |
|---|---|
| **Category** | stylise |
| **Valid layers** | fg / bg / all |
| **Signature** | `pointillize=radius` |
| **Backed by** | CIPointillize |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "bg:pointillize=15"
```
