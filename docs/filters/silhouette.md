# `silhouette`

> Fill the subject with one colour.

| Field | Value |
|---|---|
| **Category** | mask-aware fg |
| **Valid layers** | fg only |
| **Signature** | `silhouette=color=#hex` |
| **Backed by** | CIConstantColorGenerator masked |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "fg:silhouette=color=#005577"
```
