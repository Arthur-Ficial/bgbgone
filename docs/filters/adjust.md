# `adjust`

> Brightness / contrast / saturation in one filter call.

| Field | Value |
|---|---|
| **Category** | tone+colour |
| **Valid layers** | fg / bg / all |
| **Signature** | `adjust=brightness=B:contrast=C:saturation=S` |
| **Backed by** | CIColorControls (3 params) |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "bg:adjust=brightness=-0.1:contrast=1.2:saturation=0.5"
```
