# `scale`

> Scale subject around its centre.

| Field | Value |
|---|---|
| **Category** | geometric |
| **Valid layers** | fg only |
| **Signature** | `scale=factor` |
| **Backed by** | CIAffineTransform around centre |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "fg:scale=0.7"
```
