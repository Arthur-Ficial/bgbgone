# `zoom-blur`

> Radial zoom blur outward from a centre.

| Field | Value |
|---|---|
| **Category** | spatial |
| **Valid layers** | fg / bg / all |
| **Signature** | `zoom-blur=center=X,Y:amount=A` |
| **Backed by** | CIZoomBlur |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "bg:zoom-blur=center=0.5,0.5:amount=35"
```
