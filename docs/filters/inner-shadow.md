# `inner-shadow`

> Shadow inside the matte for depth.

| Field | Value |
|---|---|
| **Category** | mask-aware fg |
| **Valid layers** | fg only |
| **Signature** | `inner-shadow=blur=B:offset=X,Y:opacity=O:color=#hex` |
| **Backed by** | Invert+blur+intersect+tint |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "fg:inner-shadow=blur=10:offset=2,2:opacity=0.7:color=#000"
```
