# `edge-work`

> Line-art edges with adjustable line weight.

| Field | Value |
|---|---|
| **Category** | stylise |
| **Valid layers** | fg / bg / all |
| **Signature** | `edge-work=radius` |
| **Backed by** | CIEdgeWork |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "all:edge-work=3"
```
