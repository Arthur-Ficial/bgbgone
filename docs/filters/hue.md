# `hue`

> Rotate hue around the colour wheel.

| Field | Value |
|---|---|
| **Category** | tone+colour |
| **Valid layers** | fg / bg / all |
| **Signature** | `hue=degrees` |
| **Backed by** | CIHueAdjust inputAngle (radians) |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "bg:hue=90"
```
