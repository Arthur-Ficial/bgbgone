# `rotate`

> Rotate subject around its centre.

| Field | Value |
|---|---|
| **Category** | geometric |
| **Valid layers** | fg only |
| **Signature** | `rotate=degrees` |
| **Backed by** | CIAffineTransform around centre |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "fg:rotate=15"
```
