# `contract`

> Shrink matte by N pixels (erosion).

| Field | Value |
|---|---|
| **Category** | mask-shape |
| **Valid layers** | mask only |
| **Signature** | `contract=pixels` |
| **Backed by** | CIMorphologyMinimum on mask |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "mask:contract=4"
```
