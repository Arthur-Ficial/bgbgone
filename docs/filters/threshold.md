# `threshold`

> Binarise matte at the chosen value.

| Field | Value |
|---|---|
| **Category** | mask-shape |
| **Valid layers** | mask only |
| **Signature** | `threshold=value` |
| **Backed by** | CIColorThreshold |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "mask:threshold=0.5"
```
