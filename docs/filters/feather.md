# `feather`

> Soften matte edge.

| Field | Value |
|---|---|
| **Category** | mask-shape |
| **Valid layers** | mask only |
| **Signature** | `feather=radius` |
| **Backed by** | CIGaussianBlur on mask |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "mask:feather=8"
```
