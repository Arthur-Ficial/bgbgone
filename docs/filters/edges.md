# `edges`

> Edge detection.

| Field | Value |
|---|---|
| **Category** | stylise |
| **Valid layers** | fg / bg / all |
| **Signature** | `edges=intensity` |
| **Backed by** | CIEdges |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "all:edges=2.5"
```

## Layer comparison — yoga (`--type person`)

Same filter on the valid layer(s), subject isolated via Apple Vision's person-segmentation model so neighbouring yogis don't interfere.

```bash
bgbgone yoga.jpg --type person --filter "bg:edges"
bgbgone yoga.jpg --type person --filter "fg:edges"
bgbgone yoga.jpg --type person --filter "all:edges"
```
