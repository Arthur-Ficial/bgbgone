# `box-blur`

> Box (mean) blur - flatter falloff than Gaussian.

| Field | Value |
|---|---|
| **Category** | spatial |
| **Valid layers** | fg / bg / all |
| **Signature** | `box-blur=radius` |
| **Backed by** | CIBoxBlur |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "bg:box-blur=14"
```
