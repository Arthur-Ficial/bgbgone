# `motion-blur`

> Directional blur to simulate motion.

| Field | Value |
|---|---|
| **Category** | spatial |
| **Valid layers** | fg / bg / all |
| **Signature** | `motion-blur=radius:angle` |
| **Backed by** | CIMotionBlur |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "bg:motion-blur=radius=22:angle=45"
```
