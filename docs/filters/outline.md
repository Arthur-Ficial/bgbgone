# `outline`

> Coloured outline just outside the matte boundary.

| Field | Value |
|---|---|
| **Category** | mask-aware fg |
| **Valid layers** | fg only |
| **Signature** | `outline=color=#hex:width=N` |
| **Backed by** | CIMorphologyMaximum + subtract + tint composite |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "fg:outline=color=#ffaa00:width=6"
```
