# `crystallize`

> Voronoi-cell colour mosaic.

| Field | Value |
|---|---|
| **Category** | stylise |
| **Valid layers** | fg / bg / all |
| **Signature** | `crystallize=radius` |
| **Backed by** | CICrystallize |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "bg:crystallize=30"
```
