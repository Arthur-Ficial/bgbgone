# `exposure`

> Photographic stops, additive to current exposure.

| Field | Value |
|---|---|
| **Category** | tone+colour |
| **Valid layers** | fg / bg / all |
| **Signature** | `exposure=stops` |
| **Backed by** | CIExposureAdjust inputEV |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "bg:exposure=0.8"
```
