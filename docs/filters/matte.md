# `matte`

> Output the alpha mask itself.

| Field | Value |
|---|---|
| **Category** | mask-aware fg |
| **Valid layers** | fg only |
| **Signature** | `matte` |
| **Backed by** | Emit alpha mask as RGBA |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "fg:matte"
```
