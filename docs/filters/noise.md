# `noise`

> Additive film grain.

| Field | Value |
|---|---|
| **Category** | stylise |
| **Valid layers** | fg / bg / all |
| **Signature** | `noise=amount` |
| **Backed by** | CIRandomGenerator + CISourceOverCompositing |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "all:noise=0.3"
```
