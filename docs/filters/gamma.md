# `gamma`

> Gamma curve - <1 lightens, >1 darkens midtones.

| Field | Value |
|---|---|
| **Category** | tone+colour |
| **Valid layers** | fg / bg / all |
| **Signature** | `gamma=value` |
| **Backed by** | CIGammaAdjust inputPower |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "bg:gamma=1.8"
```
