# `gloom`

> Inverse of bloom - softens shadows.

| Field | Value |
|---|---|
| **Category** | composite |
| **Valid layers** | all only |
| **Signature** | `gloom=intensity:radius` |
| **Backed by** | CIGloom |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "all:gloom=1.0:18"
```
