# `cutout`

> Subject becomes a transparent hole; background stays.

| Field | Value |
|---|---|
| **Category** | mask-aware fg |
| **Valid layers** | fg only |
| **Signature** | `cutout` |
| **Backed by** | Invert mask |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "fg:cutout"
```
