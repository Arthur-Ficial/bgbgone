# `sharpen`

> Luminance sharpen.

| Field | Value |
|---|---|
| **Category** | spatial |
| **Valid layers** | fg / bg / all |
| **Signature** | `sharpen=amount` |
| **Backed by** | CISharpenLuminance |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "all:sharpen=0.8"
```
