# `levels`

> Photoshop-style levels remap.

| Field | Value |
|---|---|
| **Category** | tone+colour |
| **Valid layers** | fg / bg / all |
| **Signature** | `levels=black=B:white=W:gamma=G` |
| **Backed by** | CIColorMatrix + CIGammaAdjust |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "bg:levels=black=0.1:white=0.9:gamma=1.2"
```

## Layer comparison — yoga (`--algo person`)

Same filter on the valid layer(s), subject isolated via Apple Vision's person-segmentation model so neighbouring yogis don't interfere.

```bash
bgbgone yoga.jpg --algo person --filter "bg:levels"
bgbgone yoga.jpg --algo person --filter "fg:levels"
bgbgone yoga.jpg --algo person --filter "all:levels"
```
