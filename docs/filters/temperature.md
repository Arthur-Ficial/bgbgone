# `temperature`

> Colour temperature shift in Kelvin.

| Field | Value |
|---|---|
| **Category** | tone+colour |
| **Valid layers** | fg / bg / all |
| **Signature** | `temperature=K` |
| **Backed by** | CITemperatureAndTint |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "bg:temperature=3500"
```
