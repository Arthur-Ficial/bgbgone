# `translate`

> Shift subject in pixels.

| Field | Value |
|---|---|
| **Category** | geometric |
| **Valid layers** | fg only |
| **Signature** | `translate=dx,dy` |
| **Backed by** | CIAffineTransform translation |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "fg:translate=120,-60"
```
