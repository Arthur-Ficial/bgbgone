# `glow`

> Soft glow halo around the subject.

| Field | Value |
|---|---|
| **Category** | mask-aware fg |
| **Valid layers** | fg only |
| **Signature** | `glow=color=#hex:radius=R:intensity=I` |
| **Backed by** | CIGaussianBlur on mask + tint + composite |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "fg:glow=color=#ffff80:radius=25:intensity=0.8"
```
