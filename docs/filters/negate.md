# `negate`

> Invert RGB - black becomes white, blues become orange.

| Field | Value |
|---|---|
| **Category** | tone+colour |
| **Valid layers** | fg / bg / all |
| **Signature** | `negate` |
| **Backed by** | CIColorInvert |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "bg:negate"
```
