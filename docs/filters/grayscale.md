# `grayscale`

> Remove all colour saturation on the chosen layer.

| Field | Value |
|---|---|
| **Category** | tone+colour |
| **Valid layers** | fg / bg / all |
| **Signature** | `grayscale` |
| **Backed by** | CIColorControls inputSaturation=0 |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "bg:grayscale"
```
