# `tint`

> Blend toward a tint colour.

| Field | Value |
|---|---|
| **Category** | tone+colour |
| **Valid layers** | fg / bg / all |
| **Signature** | `tint=color=#hex:amount=A` |
| **Backed by** | CIColorMonochrome at lower intensity |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "bg:tint=color=#ff00ff:amount=0.5"
```
