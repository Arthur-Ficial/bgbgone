# `sepia`

> Warm monochrome tint, classic vintage look.

| Field | Value |
|---|---|
| **Category** | tone+colour |
| **Valid layers** | fg / bg / all |
| **Signature** | `sepia=intensity` |
| **Backed by** | CISepiaTone |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "all:sepia=0.85"
```
