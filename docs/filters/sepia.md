# `sepia`

> Warm monochrome tint, classic vintage look.

| Field | Value |
|---|---|
| **Category** | tone+colour |
| **Valid layers** | fg / bg / all |
| **Signature** | `sepia=intensity` |
| **Backed by** | CISepiaTone |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "all:sepia=0.85"
```

## Layer comparison — yoga (`--algo person`)

Same filter on the valid layer(s), subject isolated via Apple Vision's person-segmentation model so neighbouring yogis don't interfere.

```bash
bgbgone yoga.jpg --algo person --filter "bg:sepia"
bgbgone yoga.jpg --algo person --filter "fg:sepia"
```
