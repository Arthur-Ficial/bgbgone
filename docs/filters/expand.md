# `expand`

> Grow matte by N pixels (dilation).

| Field | Value |
|---|---|
| **Category** | mask-shape |
| **Valid layers** | mask only |
| **Signature** | `expand=pixels` |
| **Backed by** | CIMorphologyMaximum on mask |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "mask:expand=4"
```
