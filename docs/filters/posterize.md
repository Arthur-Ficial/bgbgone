# `posterize`

> Quantise to N colour levels per channel.

| Field | Value |
|---|---|
| **Category** | stylise |
| **Valid layers** | fg / bg / all |
| **Signature** | `posterize=levels` |
| **Backed by** | CIColorPosterize |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "all:posterize=4"
```
