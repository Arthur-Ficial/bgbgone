# `unsharp`

> Classic unsharp mask.

| Field | Value |
|---|---|
| **Category** | spatial |
| **Valid layers** | fg / bg / all |
| **Signature** | `unsharp=radius:intensity` |
| **Backed by** | CIUnsharpMask |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "all:unsharp=radius=3:intensity=1.0"
```

## Layer comparison — yoga (`--type person`)

Same filter on the valid layer(s), subject isolated via Apple Vision's person-segmentation model so neighbouring yogis don't interfere.

```bash
bgbgone yoga.jpg --type person --filter "bg:unsharp"
```
