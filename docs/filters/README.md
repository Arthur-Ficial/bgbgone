# bgbgone filter catalogue

49 filters spanning tone+colour, spatial, stylise, composite, mask-aware fg, geometric, and mask-shape categories. Each gets one MD with synopsis, valid layers, arguments, and a real example image regenerated by [`scripts/make-filter-showcase.sh`](../../scripts/make-filter-showcase.sh) against the canonical [Red Panda fixture](../../Tests/fixtures/showcase/Red_Panda__24986761703_.jpg) (CC0, Wikimedia Commons).

Run `bgbgone --filters-list` to enumerate the catalogue from the registry itself.

## Grammar primer

```
--filter "<chain>"          repeatable
chain  := stage (";" stage)*
stage  := [layer ":"] filter ("," filter)*
layer  := fg | bg | all | mask | composite
filter := name ("=" arg (":" arg)*)?
arg    := value | key "=" value
colour := #hex | named | rgb:R,G,B | rgba:R,G,B,A
```
