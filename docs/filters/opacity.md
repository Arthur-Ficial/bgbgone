# `opacity`

> Scale alpha by value 0..1.

| Field | Value |
|---|---|
| **Category** | tone+colour |
| **Valid layers** | fg / bg / all |
| **Signature** | `opacity=value` |
| **Backed by** | CIColorMatrix alpha vector |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "bg:opacity=0.5"
```
