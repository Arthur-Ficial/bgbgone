# `vibrance`

> Saturation boost that protects already-saturated pixels.

| Field | Value |
|---|---|
| **Category** | tone+colour |
| **Valid layers** | fg / bg / all |
| **Signature** | `vibrance=amount` |
| **Backed by** | CIVibrance |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "all:vibrance=0.8"
```
