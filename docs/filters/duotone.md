# `duotone`

> Two-colour map of luminance.

| Field | Value |
|---|---|
| **Category** | tone+colour |
| **Valid layers** | fg / bg / all |
| **Signature** | `duotone=dark=#hex:light=#hex` |
| **Backed by** | CIColorMatrix on luminance |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "bg:duotone=dark=#003366:light=#ffcc00"
```
