# `duotone`

> Two-colour map of luminance.

| Field | Value |
|---|---|
| **Category** | tone+colour |
| **Valid layers** | fg / bg / all |
| **Signature** | `duotone=dark=#hex:light=#hex` |
| **Backed by** | CIColorMatrix on luminance |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "bg:duotone=dark=#003366:light=#ffcc00"
```

## Layer comparison — yoga (`--type person`)

Same filter on the valid layer(s), subject isolated via Apple Vision's person-segmentation model so neighbouring yogis don't interfere.

```bash
bgbgone yoga.jpg --type person --filter "bg:duotone"
bgbgone yoga.jpg --type person --filter "fg:duotone"
bgbgone yoga.jpg --type person --filter "all:duotone"
```
