# `emboss`

> Raised relief.

| Field | Value |
|---|---|
| **Category** | stylise |
| **Valid layers** | fg / bg / all |
| **Signature** | `emboss` |
| **Backed by** | CIConvolution3X3 with emboss kernel |

## Example

```bash
bgbgone red-panda.jpg --bg "image:red-panda.jpg" --filter "all:emboss"
```

## Layer comparison — yoga (`--algo person`)

Same filter on the valid layer(s), subject isolated via Apple Vision's person-segmentation model so neighbouring yogis don't interfere.

```bash
bgbgone yoga.jpg --algo person --filter "bg:emboss"
bgbgone yoga.jpg --algo person --filter "fg:emboss"
bgbgone yoga.jpg --algo person --filter "all:emboss"
```
